# DiceLogChecker (DiceLog)

ココフォリア（Ccfolia）のチャットログ（HTML）を読み込み、ダイス結果を集計してダッシュボードで可視化するツールです。

## 機能

- **ダッシュボード**: クリティカル、ファンブル、成功率などをグラフで可視化。キャラクターごとの集計や全体のオーバービューを確認できます。
- **成長チェッカー**: 成功した技能（STR、CONなどのステータスや正気度ロールを除く）を自動で抽出してリストアップし、成長チェックをサポートします。
- **ログビューアー**: アップロードされたログをフィルタリングして見やすく一覧表示します。

## 使い方

1. ココフォリアの部屋からチャットログ（HTML形式）をダウンロードします。
2. 本ツールを起動し、HTMLファイルをドラッグ＆ドロップまたはファイル選択からアップロードします。
3. 自動的に集計が行われ、各タブ（Dashboard, Growth Checker, Log）で結果を確認できます。

## 開発・実行方法

本プロジェクトはモノレポ構成になっており、アプリケーション本体は `app` ディレクトリに配置されています。

### ローカル実行

```bash
cd app
npm install
npm run dev
```
